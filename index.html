功能

该有的都有，多余的都没有。

从一句话的备忘到一张排得满满的待办清单，Desktop-note 只做一件事：让你把想到的东西放下来。

贴在桌面上的便签

把任意一条笔记拖到桌面上，它就变成一块可以拖动、缩放、上色的小方块。锁住位置后不会再跟着鼠标跑。

敲一下就是待办

输入 [] 或直接点工具栏，一行文字就变成可以勾选的任务。完成、取消、排序都在同一处。

到点就提醒

给任意一条笔记加时间提醒。到了点弹系统通知，同时把对应的窗口带到最前面——不会再「提醒了但没看见」。

全文搜索

标题、正文、标签一起搜。写得多也不怕，输入关键词立刻定位到那一行。

标签与文件夹

用文件夹整理归档，用标签做横向串联。回收站保留 30 天，误删还能捞回来。

数据只存在你的电脑上

没有云端同步，也没有看得见的账号系统。所有内容以 JSON 明文存在本地目录，想备份就整个文件夹拷走。

本地优先

你的笔记，不必经过别人的服务器。

Desktop-note 不会向任何地址发送你的内容。写完就算拔掉网线，一切照常。

一眼能看到数据在哪

每条笔记一个文件，索引单独一份。你可以用任何文本编辑器打开它。

常见问题

几个也许你正想问的。

笔记会不会被上传到云端？
不会。Desktop-note 没有任何服务端，所有笔记以 JSON 文件保存在你的用户目录里。要备份，把 %APPDATA%\Desktop-note 整个文件夹复制走就行。
卸载后我的笔记还在吗？
还在。卸载程序只删除应用本体，不会动你的笔记数据目录。想彻底清除，手动删除上面那个文件夹即可。
可以在多台电脑之间同步吗？
目前不能。如果你确实有跨设备需求，可以把数据目录放进网盘做同步，但请注意两台电脑同时打开时可能产生冲突。
提醒能不能可靠地弹出来？
到点时会同时做三件事：发送系统通知、弹出应用内提醒框、把对应的窗口移到最前面并显示出来。即便系统把它设置成勿扰模式，至少窗口会浮出来。请注意 Windows 的电池优化可能会影响后台计时。
支持深色模式吗？
支持。默认跟随系统主题，也可以在设置里手动指定浅色或深色。桌面便签同样会跟着切换。

1. 一句话说明

Desktop-note 不会收集你的笔记内容，也不会收集任何可以识别到你个人的信息。应用在你的电脑上独立运行，没有账号体系，没有服务端，也没有用于统计使用行为的埋点代码。

如果你只想知道结论

写下的每一个字都只存在于你自己的硬盘上。我们看不到，也拿不到。

2. 我们收集哪些信息

我们不主动收集任何信息。具体来说，Desktop-note 在运行过程中不会：

  • 上传笔记正文、标题、标签、待办清单或提醒内容
  • 要求注册账号、绑定手机号或邮箱
  • 读取通讯录、相册、位置、麦克风、摄像头等敏感资源
  • 嵌入广告 SDK 或用于广告归因的标识符
  • 采集崩溃堆栈、使用时长、点击路径等行为数据

3. 本地存储的数据

你创建的所有内容，连同偏好设置，都以 JSON 明文文件保存在当前 Windows 用户的应用数据目录中：

  • %APPDATA%\Desktop-note\notes\ — 每条笔记一个独立文件
  • %APPDATA%\Desktop-note\index.json — 索引
  • %APPDATA%\Desktop-note\settings.json — 界面语言、主题、圆角等偏好

这些文件只有登录到本机 Windows 账户的用户才能读取。卸载应用时不会删除它们，你需要手动移除上述目录才能彻底清理。也正因为是明文，你可以随时用任何文本编辑器打开、导出或备份。

4. 系统通知

当你为某条笔记设置了时间提醒，到达时间后应用会通过 Windows 通知系统在本地弹出提示，并在应用内显示提醒条、把相关窗口移到最前。通知在设备本地生成，不会经过我们的服务器——因为我们没有服务器。

是否允许通知弹出，由 Windows「设置 → 系统 → 通知」统一管理，你可以随时关闭。

5. Microsoft Store 版本

如果你是通过 Microsoft Store 安装的 Desktop-note，那么Microsoft 作为分发方，可能会收集该应用的安装次数、崩溃摘要与设备兼容性等遥测信息。这部分数据处理遵循 Microsoft 隐私声明，不由我们控制，也不包含你的笔记内容。

你也可以在 Windows「设置 → 隐私和安全性 → 诊断和反馈」中调整相关开关。

6. 官网与托管

你当前浏览的 Desktop-note 官网是一个纯静态站点，由 Netlify 提供 CDN 分发。我们没有在页面中植入统计脚本、广告 pixels 或第三方 cookie，不使用 Cookie 追踪你的浏览行为。

出于安全与运维需要，托管方 Netlify 在处理请求时会临时生成服务器日志，其中可能包含 IP 地址、User-Agent 与访问时间。这类日志由托管方按自身政策留存，我们不会将其用于用户画像。

7. 第三方服务

应用本体不包含任何第三方 SDK、分析工具或广告组件。官网未接入 Google Analytics、Meta Pixel 或任何类似的统计服务。若未来引入会改变上述承诺的服务，我们会先更新本政策，并在应用内提前告知。

8. 儿童隐私

Desktop-note 面向普通大众，无意收集 13 岁以下儿童的个人信息。由于应用本身不收集任何信息，这一过程也不会发生。如你是监护人并认为孩子向我们提供了个人信息，请通过下方邮箱联系我们。

9. 数据安全与留存

由于数据从未离开你的设备，保护的主体责任在你的操作系统层面：建议启用 Windows 账户密码、BitLocker 磁盘加密，并保管好自己的设备。

  • 删除到回收站的笔记会保留 30 天，之后由应用自动清理
  • 清理后的数据会被真正删除，不留副本
  • 我们不持有你的任何数据，因此也无从「删除你在我们服务器上的数据」

10. 你的权利

无论你身处何地，你对自己设备上的笔记拥有完整的访问、更正、导出与删除权利，这些操作在应用内即可完成，无需向我们提出申请。

若你所在地区适用 GDPR、CCPA 等法规，由于我们不作为数据控制者持有你的个人数据，因此不存在可供查询、更正或删除的记录。若你有疑问，欢迎与我们联系。

11. 政策更新

当我们调整数据处理方式时，会更新本页面顶部的「最近更新日期」，并在必要时于应用内发布提示。重大变更会以更醒目的方式告知你。

12. 联系我们

关于本隐私政策的任何疑问、意见或请求，都可以发送邮件到 hello@example.com，我们会在合理时间内回复。
